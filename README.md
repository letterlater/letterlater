## 🌟 About LetterLater

LetterLater is a modern platform that helps you capture today's thoughts, dreams, and moments to rediscover them in the future. Whether it's a year from now or a decade ahead, your letters arrive exactly when you need them most.

### ✨ Key Features
- 🔒 **Secure & Private** - End-to-end encrypted letter storage
- ⏰ **Flexible Scheduling** - Deliver letters from days to decades in the future
- 📱 **Cross-Platform** - Web app with mobile-responsive design
- 📸 **Rich Media Support** - Text, photos, videos, and audio messages
- 💎 **Premium Features** - Advanced scheduling, analytics, and customisation
- 🎁 **Referral Program** - Reward users for sharing the platform

## 🚀 Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express, TypeScript
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT with 2FA support
- **File Storage**: Cloudinary for media uploads
- **Email**: Brevo/SendinBlue for notifications
- **Payments**: Stripe & PayPal integration
- **Deployment**: Docker, CI/CD pipelines
